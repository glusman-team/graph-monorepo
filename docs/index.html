graph-monorepo

Monorepo for ISB multiomics knowledge-graph pipelines: a Dagster deployment hosting independent DAG code locations, each building its own knowledge graph on shared Python libs and Go workers. KGX ndjson is the only KG output format.

Documentation

  • DAKP: Drug Approvals Knowledge Provider knowledge graph

    The ported DAKP pipeline: FDA and EMA approved drug-disease treatment relationships, observed uses from FAERS and Canada Vigilance, and text-mined contraindications, emitted as validated KGX. Sources, the ICD-10-CM poison screen, release history, and how to run it.

The repo in one minute

PathWhat lives there
dagster/projects/<name>/one DAG = one code location = one self-contained workspace (dagster defs, a dagster-free pipeline package, non-Python workers)
dagster/libs/shared libraries: pydantic domain models, the KGX writer + QC, dagster pipes helpers
nix/devshell and runtime apps; every tool comes from the flake
docs/this site

Nx runs cached tests across the Python packages and the Go workers; nix flake check, dg check defs, and golangci-lint gate every push (see CI).
