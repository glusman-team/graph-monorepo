## Choose the right system

| Your goal                                                               | System             | Output                                             |
| ----------------------------------------------------------------------- | ------------------ | -------------------------------------------------- |
| Build a drug-approval knowledge graph from regulator and safety sources | DAKP               | Validated KGX `nodes.ndjson` and `edges.ndjson`    |
| Give an existing KGX relationship a readable permanent page             | Linkouts           | Compressed serving-index documents read by Phoenix |
| Understand fields shared by the Go writer and Elixir reader             | Linkouts contracts | Byte-stable stored-document fixtures               |

<Card title="The format rule matters">
  DAKP-style pipelines publish KGX NDJSON only. Linkouts consumes KGX and materializes a serving
  index. Its zstd envelopes are not another knowledge-graph publication format.
</Card>
